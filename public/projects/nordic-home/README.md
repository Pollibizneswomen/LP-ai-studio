# Nordic Home — модуль 01

Полноценный фундамент интернет-магазина.

Реализовано:
- адаптивная шапка;
- mega menu;
- мобильное меню;
- живой поиск;
- избранное;
- корзина;
- localStorage;
- счётчики состояния;
- toast-уведомления;
- общая дизайн-система;
- карточки товаров из единого массива данных;
- адаптивная главная страница.

Запуск:
npm install
npm run dev


## Модуль 02 — каталог

Добавлено:
- 18 товаров в единой базе данных;
- фильтрация по категориям, комнатам, цене, материалам и цветам;
- фильтры наличия, новинок и скидок;
- сортировка;
- поиск внутри каталога;
- URL-параметры фильтров;
- активные filter chips;
- переключение сетки 2/3/4 колонки;
- пагинация;
- мобильный drawer фильтров;
- интеграция с корзиной и избранным.


## Модуль 04 — корзина и оформление заказа

Добавлено:
- полноценная корзина с изменением количества и удалением товаров;
- автоматический пересчёт стоимости;
- бесплатная доставка от 80 000 ₽;
- промокоды NORDIC10 и WELCOME15;
- рекомендации товаров;
- трёхшаговый checkout;
- контактные данные и валидация;
- курьерская доставка или самовывоз;
- дополнительная сборка;
- три способа оплаты;
- сохранение демонстрационного заказа в localStorage;
- экран успешного оформления;
- адаптивная версия.

## Модуль 05 — личный кабинет
- обзор и статистика;

- история и повтор заказов;
- избранное с добавлением в корзину;
- адреса доставки;

## Модуль 06 — финальная полировка

Добавлены страницы: About, Contacts, FAQ, Delivery, Warranty, Returns, Privacy, Terms и 404.
Добавлены favicon, web manifest, robots.txt, sitemap.xml, Open Graph cover и vercel.json.
Глобальные улучшения: loader, reveal-анимации, lazy loading, кнопка наверх, cookie-баннер, accessibility skip-link, адаптивные информационные страницы и финальные hover-эффекты.

### Публикация
1. Выполнить `npm install`.
2. Проверить проект командой `npm run dev`.
3. Собрать командой `npm run build`.
4. Импортировать репозиторий в Vercel.
